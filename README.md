# Portfólio Web 1 - Francisco Carlos

## 📋 Sobre o Projeto

Este é o trabalho final da disciplina de **WEB 1** do curso de **Gestão da Tecnologia da Informação**. O projeto consiste em um portfólio pessoal desenvolvido com tecnologias web, demonstrando conhecimentos em HTML5, CSS3 e JavaScript.

## 🌐 Acesso ao Projeto

**🔗 [Visualizar no GitHub Pages](https://franciscograveli.github.io/portifolio-web-1/)**

## 🛠️ Tecnologias Utilizadas

### Frontend
- **HTML5** - Estrutura semântica
- **CSS3** - Estilização com variáveis CSS e flexbox
- **JavaScript (ES6+)** - Interatividade e validações
- **SweetAlert2** - Notificações elegantes

### APIs Externas
- **ImgFlip API** - Carregamento dinâmico de memes


## 📁 Estrutura do Projeto

```
portifolio-web-1/
├── index.html              # Página inicial
├── assets/
│   ├── css/
│   │   ├── style.css       # Estilos principais
│   │   ├── contact.css     # Estilos da página de contato
│   │   ├── project.css     # Estilos da página de projetos
│   │   ├── about.css       # Estilos da página sobre
│   │   └── extras.css      # Estilos adicionais
│   ├── js/
│   │   ├── meme.js         # Carregamento de memes
│   │   └── contactFormValidator.js # Validação do formulário
│   ├── img/                # Imagens do projeto
│   └── favicon/            # Ícones do site
└── views/
    ├── contato.html        # Página de contato
    ├── projetos.html       # Página de projetos
    └── sobre.html          # Página sobre
```


## 🚀 Como Executar

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/franciscograveli/portifolio-web-1.git
   ```

2. **Navegue até o diretório:**
   ```bash
   cd portifolio-web-1
   ```

3. **Abra o arquivo index.html** em qualquer navegador moderno

## 📱 Responsividade

O projeto foi desenvolvido com abordagem **mobile-first**, garantindo:
- **Breakpoints** para diferentes tamanhos de tela
- **Layout flexível** que se adapta ao conteúdo
- **Navegação otimizada** para dispositivos móveis
- **Imagens responsivas** com object-fit

## 🔧 Funcionalidades JavaScript

### Carregamento de Memes
- **API Integration** com ImgFlip
- **Seleção aleatória** de memes
- **Fallback** para imagem padrão
- **Loading state** durante requisições

### Validação de Formulário
- **Validação em tempo real** dos campos
- **Feedback visual** com SweetAlert2
- **Prevenção de envio** com campos vazios
- **Foco automático** em campos com erro
